Every neighborhood has a landscape

A neighborhood's visits spread over the city's venues as a field, sitting in the low ground of an energy landscape shaped by attraction, travel time, visitor type and habit. The oval summarises it as a habitual core inside a wider range.

Equation and program
πk(v | c) ∝ exp(−Uk(c, v))    p⁰c = Σk wck πk
def field(c):                       # where neighborhood c's visits go
    k = sample(Categorical(w[c]))   # visitor type
    U = -(attract + tilt[k] - beta[k] * travel[c] + habit[c])
    return softmax(-U)

The records hide the landscape

The data provider sees a small panel, withholds counts below 2 and reports 2 to 4 as 4. The model treats records as censored draws from the latent field and infers the field behind them.

Equation and program
Ycvt ~ Poisson(nct · pcv), seen through the censoring rule
def records(c, t):
    y = sample(Poisson(n[c, t] * field(c)))
    return censor(y)        # below 2 withheld; 2 to 4 reported as 4

The landscape moves

The true landscape drifts and, midway, the main anchor loses most of its visits to another venue. A filter carries the state forward and corrects it with each month of censored records.

Equation and program
Ut = Ut−1 + ηt    st = ρ st−1 + E[Yt | records, st−1]
def step(U_prev):
    return U_prev + sample(Normal(0, sigma))    # slow drift
state = filter(step, records)   # predict, then correct, each month

What makes neighborhoods differ

No record states how rigid a neighborhood's routines are, what distance costs it or how far its EV households depend on public charging. Each trait is inferred from behaviour under a shared prior, and each changes the model's predictions.

Equation and program
θc ~ N(B xc, Σ)    Uc = U(θc)    λc = λ · g(θc)
trait[c] ~ Normal(B @ demographics[c], Sigma)   # shared prior
habit[c]  = anchors[c] ** rigidity[c]
beta[c]   = beta * sensitivity[c]
lift[c]   = lam * (0.5 + 1.5 * dependence[c])

A station opens

A station lowers the energy of its host venue for households with an EV. They re-choose from the whole field: the host gains and every other venue gives up a little. Click a venue to open or close a station.

Equation and program
πEV ∝ π · (1 + λ)[v hosts a station]    p = (1 − q) p⁰ + q pEV
def respond(c, hosts):
    ev = field(c) * (1 + lift[c]) ** is_host(hosts)   # EV households only
    return (1 - q[c]) * field(c) + q[c] * normalise(ev)
with do(hosts = hosts | {v}):                         # intervention
    after = respond(c, hosts)

Which law is true?

The model holds three rival response laws and updates its belief with every opening it observes. It can also choose where to look: the site whose outcome best separates the rivals.

laws   = [no_response, opening_year_only, lasting]

The frontier of plans

Every plan trades reach among current EV owners against reach into a target group. Sweeping the planner's objective traces the frontier of what is possible by 2030; plans that ignore activity spaces fall inside it.

Program 
def plan(w):                    # w: weight on the target group
    return argmax(sites, (1 - w) * access(ev_owners) + w * access(target))
frontier = [outcome(plan(w)) for w in grid(0, 1)]

What already runs on real data

The demonstration above runs live on synthetic data placed on Seattle's real shoreline. It mirrors a model being built on the Seattle metropolitan area: 716 neighborhoods, about 36,000 venues, six years of monthly visit records and more than 1,300 charging-station openings.

Why it matters beyond charging

A charging station is one intervention on one city. The same four parts apply wherever something new is placed among people's routines: a latent state learned from censored mobility records, a response law identified from natural experiments, a learned account of how sites get chosen, and a planner that searches inside the model.

Transit stops, clinics, grocery stores and cooling centres all change the landscape a neighborhood moves on. A model that holds the landscape, and not only the access score read off it, can say what a new place would do before it is built, and for whom.
